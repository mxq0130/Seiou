## 为什么博客需要极简设计？

好的博客设计应该**隐身**——让读者专注于内容，而不是被花哨的 UI 分散注意力。

### 核心原则

1. **内容第一**
   排版清晰、阅读舒适是博客最重要的设计目标

2. **减少认知负担**
   导航简单、布局一致、交互可预测

3. **善用留白**
   适当的空白让内容呼吸，提升阅读体验

4. **颜色克制**
   主色 + 辅色 + 点缀色，不超过 5 种

## 字体排印

字体是博客设计的基石：

- **正文**：16px 基准，1.6 行高
- **标题**：清晰的层级关系
- **代码**：等宽字体，易读

## 响应式是必须的

现在超过 50% 的流量来自移动设备，响应式不是选项，是必需。

```css
/* 移动优先的设计 */
.container {
  padding: 1rem;
}

@media (min-width: 768px) {
  .container {
    padding: 2rem;
    max-width: 720px;
  }
}
```

## 总结

> 完美不是没有什么可以添加，而是没有什么可以去掉。

设计博客时，时刻问自己：这个元素真的必要吗？去掉它会影响内容传达吗？
