## 为什么要自己搭建博客？

拥有一个独立的博客意味着你对自己的内容有完全的控制权。没有平台限制，没有广告干扰，没有算法操控。

### 技术选型

| 方案 | 优点 | 缺点 |
|------|------|------|
| 静态站点 (Astro/Hugo) | 速度快、部署简单 | 无动态功能 |
| 全栈框架 (Next.js) | 功能强大 | 复杂度高 |
| WordPress | 生态丰富 | 性能一般 |

### 推荐方案：Astro + Markdown

1. 使用 Astro 构建静态站点
2. 用 Markdown/MDX 编写文章
3. 部署到 Vercel 或 Cloudflare Pages
4. 用 Twikoo 或自建评论系统

### 域名和部署

选择一个好记的域名，推荐使用 `.com` 或 `.me` 后缀。

```bash
# 构建
npm run build

# 部署到 Vercel
vercel --prod
```

一切就绪后，你的博客就向全世界开放了。
