## Tailwind CSS v4 新特性

Tailwind CSS v4 带来了许多令人兴奋的改进：

### CSS-first 配置

告别 `tailwind.config.js`，现在直接在 CSS 中配置一切：

```css
@import "tailwindcss";

@theme {
  --color-primary: #6750A4;
  --font-sans: "Noto Sans SC", sans-serif;
}
```

### 自动内容检测

v4 自动检测你的模板文件，无需手动配置 `content` 路径。

### 原生 CSS 变量支持

```css
:root {
  --color-bg: #FFFBFE;
}

/* 在 Tailwind 中使用 */
@theme {
  --color-bg: var(--color-bg);
}
```

## 响应式设计

Tailwind 的响应式断点简单直观：

| 断点 | 宽度 | 设备 |
|------|------|------|
| `sm` | 640px | 大屏手机 |
| `md` | 768px | 平板 |
| `lg` | 1024px | 笔记本 |
| `xl` | 1280px | 桌面 |

## 实用技巧

1. **善用 `@layer` 组织样式**
2. **使用 `@apply` 提取重复模式**
3. **合理使用 `group` 和 `peer` 修饰符**
4. **动画使用 Tailwind 内置的 `animate-*`**

## 小结

Tailwind CSS v4 是一次重大升级，CSS-first 的配置方式让定制主题变得前所未有的简单。
