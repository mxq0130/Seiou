## 🎉 博客正式上线！

经过数周的开发与调试，**小破站** 终于在 2026 年 6 月 4 日正式上线了！

这是一个完全自主开发的个人博客——从 UI 设计、前后端、数据库到服务器部署，每一行代码都亲手敲出。这篇首发文章记录下整个项目的来龙去脉，也算给自己一个交代。

---

## 📋 项目缘起

写博客这么多年，用过 WordPress、Hexo、Hugo、Notion、语雀……每次迁移都是灾难。要么被平台绑架，要么定制性太差，要么预览体验糟糕。

> **核心诉求很朴素**：一个自己说了算、长得好看、写 Markdown 就能发、有完整后台管理的博客。

既然没有现成方案完全满意，那就自己造一个。

---

## 🏗️ 技术选型

整体采用 **前后端分离的三层架构**，支持双模式切换：

### 前端：Astro 6 + Tailwind CSS 4

| 技术 | 选型理由 |
|------|----------|
| **Astro 6** | Island 架构，零 JS 输出博客页，SSR 模式兼容动态路由 |
| **Tailwind CSS 4** | 原子化 CSS，配合 CSS 变量实现樱花星夜主题 |
| **MDX** | Markdown + JSX 混写，文章内嵌组件不是梦 |
| **PhotoSwipe** | 图集灯箱，移动端手势支持一流 |

### 后台管理：React 19 + Ant Design 6

| 技术 | 选型理由 |
|------|----------|
| **React 19** | 生态成熟，社区活跃 |
| **Ant Design 6** | 企业级 UI 库，表格/表单开箱即用 |
| **React Router 7** | SPA 路由，API 拦截器统一鉴权 |

### 后端：Express + Prisma + MySQL

| 技术 | 选型理由 |
|------|----------|
| **Express** | 轻量灵活，TypeScript 友好 |
| **Prisma ORM** | 类型安全的数据库操作，迁移管理方便 |
| **MySQL 8.0** | 可靠的关系型数据库，1Panel 一键部署 |
| **JWT** | 无状态认证，前后端分离标配 |

### 部署：1Panel + PM2 + OpenResty

- **服务器**：雨云香港 2核2G
- **面板**：1Panel（服务器管理瑞士军刀）
- **进程守护**：PM2（Node.js 进程管理）
- **反向代理**：OpenResty（Nginx + Lua）

## 🐛 遇到的坑与解决方案

### 坑 1：Astro SSR 构建报错 `node is not defined`

**问题**：`astro.config.mjs` 中漏掉了 `import node from '@astrojs/node'`，导致 Vite 打包时找不到 `node` 变量。

**解决**：添加 import 语句，并根据 `ASTRO_MODE` 环境变量动态切换 adapter。

```js
import node from '@astrojs/node';
const isStatic = process.env.ASTRO_MODE === 'static';

export default defineConfig({
  output: isStatic ? 'static' : 'server',
  adapter: isStatic ? undefined : node({ mode: 'standalone' }),
});
```

### 坑 2：`@astrojs/node` 版本不兼容

**问题**：`@astrojs/node@10.1.2` 与 `astro@6.3.7` 不兼容，Rollup 构建时找不到 `createRequestFromNodeRequest`。

**根因**：Astro 6.3+ 将 `createRequestFromNodeRequest` 重命名为 `createRequest`，但旧版 adapter 还在用旧名字。

**解决**：升级到 `astro@6.4.3` + `@astrojs/node@10.1.3` 组合。

### 坑 3：Prisma 引擎平台不兼容

**问题**：Windows 本地 `prisma generate` 生成的引擎在 Linux 服务器上无法运行。

```
PrismaClientInitializationError: 
Prisma Client could not locate the Query Engine for runtime "debian-openssl-1.1.x".
```

**解决**：在 `schema.prisma` 中添加 `binaryTargets`：

```prisma
generator client {
  provider      = "prisma-client-js"
  binaryTargets = ["native", "debian-openssl-1.1.x"]
}
```

### 坑 4：Nginx 反向代理 404

**问题**：管理后台 `/admin/` 请求返回 404 或 500。

**根因**：1Panel 的 OpenResty 运行在 Docker 容器内，无法访问宿主机的文件路径。

**解决**：
1. 将管理后台构建产物复制到容器挂载目录 `/opt/1panel/www/admin/`
2. Nginx 配置使用容器内路径 `alias /www/admin/`
3. 使用 `root` 而非 `alias` 避免路径拼接问题

### 坑 5：React Router 路径混乱

**问题**：导航菜单点击后出现 `/posts/archive/` 这种错误拼接路径。

**根因**：`astro.config.mjs` 配置了 `base: './'` 相对路径，加上 NavBar 使用 `./archive/` 相对链接，导致浏览器在当前 URL 基础上拼接而非从根路径导航。

**解决**：SSR 模式下改用 `base: '/'`，所有导航链接使用绝对路径 `/archive/`。
