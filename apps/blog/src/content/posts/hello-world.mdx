## 为什么选择 Astro？

Astro 是一个现代化的静态网站生成器，它的核心理念是**按需加载 JavaScript**。

### 主要优势

- **零 JS 默认**：生成的页面默认不包含 JavaScript
- **多框架支持**：可以在同一项目中使用 React、Vue、Svelte 等
- **内容优先**：为内容型网站而生，完美支持 Markdown/MDX
- **性能卓越**：Lighthouse 评分轻松满分

### 我的选择

经过对比多个博客框架，我最终选择了 Astro，原因如下：

1. 对 Markdown 的原生支持非常出色
2. Tailwind CSS 集成简单方便
3. 社区活跃，主题丰富
4. 性能表现优秀

## 搭建过程

```bash
# 创建项目
npm create astro@latest

# 添加 Tailwind CSS
npx astro add tailwind

# 添加 MDX
npx astro add mdx
```

整个过程非常顺滑，几乎没有遇到什么障碍。

## 主题设计

我选择了二次元风格的主题设计，参考了 Material Design 3 的设计规范：

- **配色**：紫色主色调，搭配樱花粉点缀
- **字体**：Noto Sans SC 作为主要字体
- **动效**：微妙的悬浮效果和过渡动画
