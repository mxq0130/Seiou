## 什么是 Markdown？

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它允许你使用易读易写的纯文本格式编写文档，然后转换为结构化的 HTML。

### 基本语法一览

| 元素 | 语法 | 效果 |
|------|------|------|
| 标题 | `# H1` `## H2` `### H3` | 六级标题 |
| 粗体 | `**文字**` | **粗体** |
| 斜体 | `*文字*` | *斜体* |
| 链接 | `[标题](url)` | 超链接 |
| 图片 | `![alt](url)` | 嵌入图片 |
| 代码 | `` `code` `` | 行内代码 |

### 代码块

支持多种语言的语法高亮：

```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

async function fetchUser(id: number): Promise<User> {
  const res = await fetch(`/api/users/${id}`);
  return res.json();
}
```

## 总结

Markdown 的核心理念是**内容优先**——让你专注于写作本身，而非排版细节。无论你是写博客、文档还是笔记，Markdown 都是最佳选择。
