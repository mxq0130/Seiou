## React Server Components

React 19 的服务器组件让组件可以直接在服务端访问数据库和文件系统，无需额外的 API 层。

### 服务器组件 vs 客户端组件

```tsx
// 服务器组件（默认）
async function PostList() {
  const posts = await db.post.findMany();
  return (
    <ul>
      {posts.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
}
```

### 使用原则

- 服务器组件不能使用 `useState`、`useEffect` 等客户端 Hook
- 客户端组件需要在文件顶部添加 `"use client"` 指令
- 服务器组件可以导入客户端组件，反之不行

这彻底改变了 React 的架构范式。
