## Tailwind CSS v4

Tailwind CSS v4 是一个重大更新，重新设计了配置方式，使其更加符合现代 CSS 标准。

### CSS 优先配置

v4 最大的变化是**用 CSS 替代 JavaScript 配置**：

```css
@import "tailwindcss";

@theme {
  --color-primary: #E8738A;
  --color-secondary: #6B7DB3;
  --font-heading: "Noto Serif SC", serif;
}
```

### 性能提升

- 构建速度提升 **3-5 倍**
- 使用 Rust 引擎 Oxc 解析 CSS
- 更好的 Tree Shaking

### 暗色模式

```html
<div class="bg-white dark:bg-gray-900">
  <h1 class="text-gray-900 dark:text-white">标题</h1>
</div>
```

内置的 `dark:` 变体让暗色模式适配变得极其简单。
