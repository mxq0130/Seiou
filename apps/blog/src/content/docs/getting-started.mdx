## 欢迎使用二次元博客

这是一个基于 Astro 构建的二次元风格个人博客。

### 主要功能

- 📝 **博客文章** - 支持 Markdown 编写，代码高亮
- 📚 **文档系统** - 层级文档展示
- 🖼️ **图集** - 图片上传与瀑布流展示
- 🎬 **追番** - 对接 B 站追番数据
- 🔗 **友链** - 友情链接管理与申请
- 🌙 **双色主题** - 浅色/深色模式切换
- 📱 **响应式** - 手机/平板/桌面全适配

### 注册账号

点击右上角的「登录」按钮，可以注册一个新账号。注册后可以：
- 发表评论
- 上传图片到图集
- 申请友链
