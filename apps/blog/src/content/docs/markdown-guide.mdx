## 基础语法

### 标题

```md
# 一级标题
## 二级标题
### 三级标题
```

### 文本格式

```md
**加粗文字**
*斜体文字*
~~删除线~~
`行内代码`
```

### 链接与图片

```md
[链接文字](https://example.com)
![图片描述](https://example.com/image.png)
```

## 高级用法

### 代码块

````md
```javascript
const hello = "Hello World";
console.log(hello);
```
````

### 表格

```md
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
```

### 引用

```md
> 这是一段引用文字
> 可以多行
```

### 任务列表

```md
- [x] 已完成
- [ ] 未完成
```

## 提示框

本博客支持自定义提示框组件：

```mdx
<Note type="info">
  这是一条提示信息
</Note>

<Note type="warning">
  这是一条警告信息
</Note>
```
