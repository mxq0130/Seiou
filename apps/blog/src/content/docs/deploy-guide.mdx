## 部署方式

本博客支持多种部署方式：

### Docker 部署（推荐）

```bash
docker compose up -d
```

### 静态部署

将构建产物部署到 Nginx：

```bash
npm run build
# 将 dist/ 目录部署到服务器
```

### 平台部署

支持一键部署到：
- Vercel
- Netlify
- Cloudflare Pages

## 环境变量

部署时需要设置以下环境变量：

```env
DATABASE_URL=mysql://...
JWT_SECRET=your-secret
S3_ENDPOINT=https://...
S3_ACCESS_KEY=your-key
S3_SECRET_KEY=your-secret
```

## 域名配置

1. 将域名解析到服务器 IP
2. 在 Nginx 中配置反向代理
3. 申请 SSL 证书
