# UI/UX 设计规范

## 设计风格

二次元动漫风格博客。设计参考 Mizuki 的布局和功能结构，但视觉上做差异化——不走 Material Design 3 路线，而是采用更柔和、更有温度的「樱花与星夜」动漫主题。

### 设计关键词
- 🎀 **柔和**：大面积暖色渐变、毛玻璃效果
- 🌸 **治愈**：樱花粉 + 蓝紫渐变的配色
- ✨ **灵动**：微妙的悬浮动画、粒子装饰
- 🌙 **星夜**：深色模式下呈现星空氛围

### 参考来源
- 布局结构参考 [Mizuki](https://github.com/LyraVoid/Mizuki)（功能对齐，风格不同）
- 配色灵感来自日本动画「秒速五厘米」「你的名字」

## 排版

### 字体

| 用途 | 字体 | 备选 |
|------|------|------|
| 站点标题 | `ZCOOL KuaiLe` (站酷快乐体) | 系统默认中文字体 |
| 文章标题 | `Noto Serif SC` (思源宋体) | 系统宋体 |
| 正文 | `Noto Sans SC` (思源黑体) | 系统默认中文字体 |
| 代码 | `JetBrains Mono` | `Fira Code` |

### 字号

| 级别 | 大小 | 行高 | 用途 |
|------|------|------|------|
| h1 | 2rem / 32px | 1.3 | 页面标题 |
| h2 | 1.5rem / 24px | 1.35 | 区块标题 |
| h3 | 1.25rem / 20px | 1.4 | 子标题 |
| body | 1rem / 16px | 1.7 | 正文 |
| small | 0.875rem / 14px | 1.5 | 辅助文字、元信息 |
| caption | 0.75rem / 12px | 1.4 | 标签、脚注 |

### 文章排版 (Prose)

- 正文行高 1.7，段落间距 1.2em
- 标题与正文间距较大（h2 前 2em，h3 前 1.5em）
- 引用块左侧 3px 渐变边框
- 链接加下划线（hover 渐变色）

## 响应式断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| sm | < 640px | 单列，侧边栏隐藏 → 底部抽屉 |
| md | 640px - 1024px | 双列变体，侧边栏可折叠 |
| lg | > 1024px | 双列：内容+侧边栏，TOC 右侧固定 |
| xl | > 1280px | 双列 + TOC 三列 |

## 阴影 & 毛玻璃

| 级别 | 值 | 用途 |
|------|-----|------|
| card | `0 2px 12px rgba(45,43,61,0.06)` | 卡片默认 |
| card-hover | `0 8px 30px rgba(45,43,61,0.10)` | 卡片悬浮 |

## 动效规范

| 类型 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 微交互 | 150ms | `ease-out` | 按钮/图标 hover |
| 卡片悬浮 | 300ms | `ease-out` | 上浮 + 阴影加深 |
| 主题切换 | 400ms | `ease-in-out` | 全局颜色过渡 |
| 页面入场 | 400ms | `ease-out` | Swup 页面切换 |
| 骨架屏 | 1.5s | `ease-in-out` | 加载闪烁动画 |

## 二次元装饰元素

- **顶部樱花飘落**：随机 5-8 片花瓣 CSS 动画（仅浅色模式，不影响性能）
- **卡片毛玻璃**：侧边栏、导航栏、Banner 遮罩使用 `backdrop-filter: blur()`
- **渐变标题**：h1 标题使用 `#E8738A → #6B7DB3` 渐变文字
- **卡片底部渐变条**：PostCard / Widget 底部 3px 渐变色条
- **封面图悬浮缩放**：hover 时 `scale(1.03)` + 亮度提升
- **深色模式星空背景**：CSS 生成的随机小点模拟星空
