# 技术选型与架构说明

## 总体架构

```
用户浏览器
    │
    ▼
┌─────────────────────────────────────────┐
│              Nginx (1Panel)              │
│       反向代理 · 静态资源 · SSL           │
├─────────────────────────────────────────┤
│   /        │   /api/*    │   /admin/*   │
│ Astro SSR │ Express API │ React SPA    │
│ (Node.js) │  (Node.js)  │ (静态文件)    │
├─────────────────────────────────────────┤
│             MySQL 8.0                    │
│        (1Panel 一键安装)                 │
├─────────────────────────────────────────┤
│         S3 兼容对象存储                   │
│         (图片/上传文件)                   │
└─────────────────────────────────────────┘
```

## 关键技术决策

1. **Astro SSR 模式**：为了支持用户登录和动态内容，使用 SSR 而非纯静态模式
2. **独立后台**：管理后台为独立 React SPA，与博客前端分离部署，降低耦合
3. **Prisma ORM**：相比直接用 SQL，Prisma 提供类型安全和自动迁移，减少手写 SQL 出错
4. **S3 兼容存储**：使用 S3 协议，后续可灵活切换云存储供应商
5. **JWT 认证**：无状态认证，适合 API 前后端分离架构
