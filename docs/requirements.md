# 项目需求文档

## 项目概述

二次元风格的个人博客网站，基于 Astro 构建。设计参考 Mizuki 博客主题，在视觉风格上做差异化改造。支持双模式运行：生产模式走 SSR + MySQL，提交模式打包为纯静态站点。

### 用户角色

| 角色 | 说明 |
|------|------|
| 管理员 | 博客所有者，拥有后台管理全部权限 |
| 注册用户 | 注册登录的访客，可评论 |
| 访客 | 未登录的浏览者，可浏览所有公开内容 |

### 构建模式

| 模式 | 数据来源 | 用途 |
|------|----------|------|
| 生产模式 (SSR) | Express API → MySQL | 线上真实运行 |
| 静态模式 (Static) | 内置 Mock 数据 | 作业提交 / GitHub Pages 演示 |

### 非功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| N-01 | 性能 | Lighthouse 评分 > 90 |
| N-02 | SEO | OG / Twitter Card / JSON-LD 结构化数据 + sitemap |
| N-03 | 安全 | JWT 鉴权、密码哈希、XSS/CSRF 防护 |
| N-04 | 可维护性 | 清晰的代码结构和文档 |
| N-05 | 双模式构建 | `ASTRO_MODE=static` 可打包为纯前端静态站点 |
| N-06 | 页面动效 | Swup 页面过渡动画、卡片悬浮效果 |
| N-07 | 无障碍 | 合适的 aria 标签、键盘导航支持 |
