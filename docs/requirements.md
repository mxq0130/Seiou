# 项目需求文档

## 项目概述

二次元风格的个人博客网站，使用 Astro 构建，部署在雨云香港服务器 + 1Panel。

### 用户角色

| 角色 | 说明 |
|------|------|
| 管理员 | 博客所有者，拥有后台管理全部权限 |
| 注册用户 | 注册登录的访客，可评论、上传图片 |
| 访客 | 未登录的浏览者，可查看文章和图集 |

## 功能需求

### 博客前台

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| F-01 | 首页 | P0 | Banner轮播 + 文章列表 + 追番动态 |
| F-02 | 文章详情 | P0 | Markdown渲染 + 目录导航 + 代码高亮 |
| F-03 | 归档页 | P1 | 按年月分类的时间轴 |
| F-04 | 文档页 | P1 | 层级文档展示 + 侧边栏 |
| F-05 | 友链页 | P1 | 友链卡片网格展示 |
| F-06 | 关于页 | P2 | 个人/站点介绍 |
| F-07 | 我的页 | P2 | 个人资料展示 |
| F-08 | 图集 | P1 | 相册瀑布流 + 灯箱预览 |
| F-09 | 追番 | P1 | 番剧卡片 + 进度 + B站同步 |
| F-10 | 用户注册/登录 | P0 | 表单 UI + JWT 认证 |
| F-11 | 搜索 | P2 | 全站文章搜索 |
| F-12 | 评论 | P1 | 文章/图集评论区 |
| F-13 | 双色主题 | P0 | 浅色/深色模式切换 |
| F-14 | 响应式布局 | P0 | 手机/平板/桌面自适应 |

### 后台管理

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| A-01 | 仪表盘 | P1 | 统计概览 |
| A-02 | 文章管理 | P0 | 增删改查 + 发布/草稿 |
| A-03 | 文档管理 | P1 | 层级管理 |
| A-04 | 图集管理 | P1 | 相册 + 图片上传 |
| A-05 | 追番管理 | P2 | 番剧增删改 + B站同步 |
| A-06 | 友链管理 | P2 | 审核 + 增删改 |
| A-07 | 用户管理 | P1 | 用户列表 + 角色权限 |
| A-08 | 评论管理 | P1 | 审核 + 删除 + 回复 |
| A-09 | 站点设置 | P1 | 基本信息 + 主题配置 |

### 非功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| N-01 | 性能 | Lighthouse 评分 > 90 |
| N-02 | SEO | 友好的 meta 标签和 sitemap |
| N-03 | 安全 | JWT 鉴权、密码哈希、XSS/CSRF 防护 |
| N-04 | 可维护性 | 清晰的代码结构和文档 |
