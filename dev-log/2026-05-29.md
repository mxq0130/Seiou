### 部署架构

```
Nginx (443/80)
├── /              → Astro SSR (Node.js)
├── /admin         → React SPA (静态文件)
├── /api/*         → Express API (Node.js)
└── 静态资源       → Nginx 直接服务
        ↓
MySQL 8.0 (1Panel 一键安装)
```

### 部署步骤（规划）

1. 服务器安装 1Panel
2. 1Panel 安装 MySQL 8.0 + Node.js
3. 配置数据库 + 导入 Schema
4. 上传项目代码
5. 构建前端：`astro build` + `vite build`
6. 配置 Nginx 反向代理
7. 配置 SSL 证书
8. 启动服务 + 健康检查

### 环境变量

```env
# .env.production
DATABASE_URL=mysql://user:pass@localhost:3306/boke
JWT_SECRET=生产环境密钥
PORT=3000
CORS_ORIGIN=https://你的域名.com
USE_MOCK=false
ASTRO_MODE=server
```
