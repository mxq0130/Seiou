## 启动方式

```bash

cd apps/server && npm run dev    # → :3000

# 终端 2: 管理后台
cd apps/admin && npm run dev     # → :3001

# 终端 3: 博客前端
cd apps/blog && npm run dev      # → :4321
```

## 遇到的 Bug

1. ScrollReveal 组件 `class="reveal-{type}"` 未被 Astro 编译 → 修复为模板字面量
2. ScrollReveal CSS `opacity:0` 导致所有内容不可见 → 移除隐藏规则，默认可见
3. 首页透明导航栏浅色模式下看不清 → 改为始终毛玻璃
4. 非首页内容被固定导航栏遮挡 → 添加 `pt-20` 安全距离
5. 内容集合 Astro 6 需要 `glob` loader + `z.date()` 而非 `z.string()`
6. `/admin` 代理无限重定向 → 去掉 `rewrite` 规则，Vite 设置 `base: '/admin/'`
