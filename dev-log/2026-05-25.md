## 遇到的问题

1. `npm create astro` Windows下依赖安装超时 → 手动 `npm install` 解决
2. Layout.astro 的 frontmatter 需放文件顶部，否则 props 无法解析
3. Astro 6 内容集合 API 变化：`src/content/config.ts` → `src/content.config.ts`，需添加 glob loader
4. `render()` 需从 `astro:content` 导入：`import { render } from 'astro:content'`，不能作为 entry 方法调用
5. 组件 import 必须在 frontmatter 中，不能放在 `<script>` 标签内
6. `astro:content` 模块只能服务端使用，客户端脚本需通过数据序列化
