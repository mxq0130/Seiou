## 遇到的问题

1. Astro 6 内容集合 API 变化：需要 `src/content.config.ts` + glob loader
2. `render()` 需从 `astro:content` 导入，不能作为 entry 方法调用
3. Astro 组件 import 必须在 frontmatter 中
4. `astro:content` 只能服务端使用
5. 全局 CSS 遗漏导入导致无样式
6. Prisma schema 多态关联需使用 targetType/targetId 而非直接 relation
7. Optional relation 字段需对应 Optional relation 声明
8. Express 5 types: `req.params` 类型为 `string | string[]`，需 `String()` 转换
