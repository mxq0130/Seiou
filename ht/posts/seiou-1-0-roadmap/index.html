星桜 1.0：博客命名与未来路线图

2026年6月16日 2 阅读 技术

博客正式命名

经过第一阶段开发，这个小破站终于有了正式的名字——

🌸 星 桜

读音：せいおう（Seiou），意为「星之樱」。

星 代表星夜蓝 (#6B7DB3)，桜 代表樱花粉 (#E8738A)。这两个颜色正是整个网站的视觉主色调。星夜下的樱花，静谧而浪漫——这就是我想通过这个博客传达的调性。

副标题：わたしの小さな星（我的小小星球）

v1.0 完成功能清单

🏠 前台（10个页面）

  • 首页 —— 全屏Hero轮播 + 功能介绍 + 统计数字
  • 文章列表 —— 分页卡片 + 分类/标签/搜索筛选
  • 文章详情 —— Markdown渲染 + 评论区
  • 归档页 —— 时间线浏览
  • 搜索页 —— 全文检索
  • 关于页 —— 个人介绍 + 技能栈 + 项目 + 时间线
  • 友链页 —— 友情链接
  • 图集页 —— 相册列表 + 详情
  • 追番页 —— 动画观看记录
  • 日记页 —— 时间线日记

⚙️ 后台（13个管理模块）

  • 仪表盘 —— 6项统计指标
  • 文章管理 —— CRUD + 置顶 + 标签 + 封面图 + 投稿审核
  • 追番管理 —— B站同步 + CRUD
  • 图集管理 —— 相册CRUD + 图片上传/��理
  • 日记管理
  • 友链管理
  • 关于页管理 —— 个人信息/头像/技能/项目/时间线
  • 用户管理 —— 角色/状态切换
  • 站点设置 —— 标题/描述/轮播图/音乐/Widget开关
  • 标签管理 —— CRUD
  • 分类管理 —— CRUD
  • 公告管理 —— CRUD + 启用/停用
  • 评论管理 —— 审核/删除

👤 用户系统

  • 注册/登录
  • JWT认证
  • 评论（需登录）
  • 文章投稿（需审核）
  • 角色权限（管理员/普通用户）

📊 技术架构

  • 博客前端：Astro 6 SSR
  • 后台管理：React 19 + Ant Design 6
  • API后端：Express + TypeScript + Prisma
  • 数据库：MySQL 8.0
  • 部署：1Panel + PM2 + OpenResty + Docker
  • 服务器：雨云香港 2核2G

📈 项目规模

  • ~120个源文件
  • 15张数据库表
  • 15个API路由模块
  • 50+次Git提交
  • 从立项到1.0历时约10天

🗺️ 未来路线图

v1.1 体验优化（近期）

  • 图片懒加载与压缩：上传图片自动压缩 + WebP转换，减少带宽
  • 骨架屏加载态：替换空白loading，提升感知速度
  • 暗色模式完善：当前暗色模式部分组件颜色不协调
  • 移动端体验优化：侧边栏折叠、触摸手势
  • 评论回复功能：支持楼中楼回复
  • 邮件通知：评论回复通知、文章审核通知
  • 友链申请系统：访客自助提交友链 → 管理员审核

v1.2 内容增强

  • RSS/Atom Feed：标准博客订阅
  • 站点地图完善
  • 全文搜索优化：接入Meilisearch或FlexSearch
  • 文章目录（TOC）：自动生成侧边目录导航
  • 相关文章推荐：基于标签和分类
  • 代码高亮：Shiki主题集成
  • 数学公式：KaTeX（已有依赖，需接入）
  • 文章加密：密码保护私密文章

v1.3 视觉升级

  • 动画库引入：Framer Motion / GSAP / Three.js
  • 页面过渡动效：Swup.js 或 View Transitions API
  • 粒子背景：Sakura粒子飘落特效
  • 3D元素：Three.js 制作3D樱花树或星空背景
  • 微交互：按钮水波纹、卡片悬浮3D翻转、滚动视差
  • 更高端的配色方案：渐变更丰富、毛玻璃效果增强

v2.0 重构计划

  • 前端框架升级：考虑迁移到Astro 7 + Svelte/Solid.js组件
  • 管理后台重构：从Ant Design换为更轻量的方案，或自建组件
  • 数据库优化：添加Redis缓存层、读写分离
  • CDN加速：图片/静态资源上云存储 + CDN
  • 国际化：中日英三语支持
  • PWA支持：离线访问、桌面安装
  • 容器化部署：Docker Compose一键启动

🧪 实验性功能

  • AI写作助手：接入LLM辅助生成文章摘要和标签
  • 语音朗读：文章TTS播放
  • 弹幕评论：像B站一样的滚动弹幕模式
  • 音乐播放器增强：接入网易云/B站API实时播放
  • 时光机：博客历史快照浏览
  • 访客地图：显示访客来源地
  • 摄影EXIF展示：图集照片显示拍摄参数
  • 自定义主题：允许访客切换配色方案

星桜 1.0 不是终点，而是一个新的起点。 每一次更新都是对「更好的个人空间」的探索。 感谢看到这里的你。

—— 写于2025年6月16日，v1.0发布之际
