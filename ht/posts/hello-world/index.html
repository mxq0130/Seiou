🎉 博客正式上线！

经过数周开发，小破站 终于在 2026 年 6 月 4 日正式上线。从 UI 设计、前后端开发、数据库到服务器部署，每行代码都亲手敲出。

📋 项目缘起

用过的博客平台：WordPress → Hexo → Hugo → Notion → 语雀。每次迁移都是灾难——要么被平台绑架，要么定制太差，要么预览难用。

核心诉求：一个自己说了算、好看、Markdown 写作、有完整后台管理的博客。

既然没现成的，就自己造。

🏗️ 技术选型

前端：Astro 6 + Tailwind CSS 4

  • Astro 6 Island 架构，SSR 模式兼容动态路由
  • Tailwind CSS 4 原子化 CSS，樱花星夜双主题
  • MDX 文章渲染 + PhotoSwipe 图集灯箱

后台：React 19 + Ant Design 6

  • 10 个管理模块（仪表盘/文章/分类/标签/用户/追番/图集/日记/友链/设置）
  • React Router 7 SPA 路由 + Axios 拦截器统一鉴权

后端：Express + Prisma + MySQL

  • Express TypeScript + Zod 参数校验
  • Prisma ORM 类型安全数据库操作
  • JWT 无状态认证 + 双模式登录（用户名/邮箱）

部署：雨云香港 + 1Panel + PM2 + OpenResty

  • 2核2G 云服务器，1Panel 面板管理
  • PM2 进程守护 + 开机自启
  • OpenResty (Nginx) 三合一反向代理

Hello World！ 感谢来访，欢迎常来逛逛 🌸
